## Status legend

| Status | Meaning |
|---|---|
| `PASSING` | A real test exists at the clause's **proper level** and asserts the guarantee. Exact test named. |
| `PARTIAL(unit)` | Genuine class-level/in-process coverage exists, but the guarantee is **not** demonstrated at the required level (edge process / wire / sim with real propagation). Missing level named in Notes. |
| `FAILING-CAPTURED` | Test exists, fails, failure captured, `@Disabled` with an `S3-BACKLOG` marker. |
| `UNIMPLEMENTED` | No test exists for the clause (the planned test name is given). |
| `ADR-RENEGOTIATED(adr-ref)` | Clause renegotiated by an accepted ADR; row closed by reference. |
| `N-A(reason)` | Clause not applicable as written (reason given). |

## Level legend

- **UNIT** — class in isolation (JUnit, single JVM, no wiring).
- **BOUNDARY** — the in-process ADR-0034 interface (`readSince`/`ReplaySource`) — this *is* the proper level for ADR-0034's own clauses.
- **SIM** — deterministic simulation over the real `RaftNode`/`ConfigStateMachine` (configd-testkit harness).
- **PROCESS** — separately running edge process over the real wire (C2 transport, mTLS), or the C1 fan-out service endpoint.
- **GATE** — a gate-3 mechanical check (JMH `-prof gc`, jcstress, static-guard test, metrics presence).

## Component legend (charter §4, `docs/session-3/charter.md` — verbatim component scopes)

- **C1 — Fan-out distribution service** (charter:104-112): consumes the ADR-0034 boundary; push-based
  cursor-acknowledged streams per subscriber; §7 subscription model; the coalescing/gap rule ("define and
  test the exact rule"); §11 backpressure — bounded per-subscriber queues, explicit overflow→catch-up
  demotion, every policy threshold a named config with a metric.
- **C2 — Edge node process** (charter:114-124): separately runnable process; transport + mTLS (ADR-0037
  deviation recorded in the charter itself, :117); versioned snapshots + delta application onto the
  lock-free read path (hot-path law inherited, brief JMH gc-profile); every read returns its cursor;
  per-session monotonic reads incl. across reconnect to a *different* fan-out endpoint; the staleness
  commit-timestamp clock + `X-Configd-Stale` serving surface live here (delta-apply/serving path).
- **C3 — Catch-up, replay, gap detection** (charter:126-131): cursor-gap detection on the edge; replay
  from the boundary or snapshot+delta re-bootstrap past the replay horizon (horizon-boundary case under
  concurrent writes); poison-pill + negative caching — implement or explicitly descope by ADR.
- **C4 — Slow-consumer policy** (charter:133-136): §7 thresholds (demotion to catch-up, quarantine,
  disconnect, re-bootstrap); each transition: a test, a metric, a structured log; sim-exercised.
- **C5 — New-edge bootstrap** (charter:138-141): zero-state join under sustained concurrent writes; no
  gap, no duplicate-application divergence; judged by the V1 snapshot–delta equivalence invariant.
- **C6 — End-to-end integration** (charter:143-149): Compose 3 control-plane + ≥3 edge processes;
  scripted scenarios (sustained writes, leader kill mid-stream, edge partition→demotion→convergence,
  fresh-edge bootstrap mid-load); RR-095 stall-seed re-run.
- **G3** — cross-cutting gate-3 mechanical rows (charter §5: JMH gc-profile check, metrics presence)
  that no single component owns.
